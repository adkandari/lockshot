# Cover Images

Place the three screenshot cover images in this directory:

1. `full-bleed.png` - Full Bleed template (iPhone habit app with "Today" list)
2. `caption-top.png` - Caption Top template ("Track every habit" caption bar)
3. `framed.png` - Framed template (iPhone with orange progress ring)

## Image Requirements

- Format: PNG
- Orientation: Portrait (phone screenshot)
- Recommended size: 800×1600px or similar aspect ratio
- Content: Actual iPhone screenshots showing the template styles

These images will be loaded as 3D book cover textures in the Complete Shelf landing page.
